# Planejamentos

Registro dos planos produzidos pelos agentes **infra-planner** e **dev-planner** antes de
serem executados por **infra-runner** / **dev-runner**.

Convenção de nomes:

- `AAAA-MM-DD-ops-<assunto>.md` — planos de infraestrutura (infra-planner)
- `AAAA-MM-DD-dev-<assunto>.md` — especificações de arquitetura/testes (dev-planner)

Atualize o arquivo existente quando o plano for revisado, em vez de duplicá-lo.
